This folder holds one sub-folder per registered student, named
<roll_number>_<name> (e.g. CS101_JohnDoe/), each containing ~40-50
cropped face images captured via the webcam by src/face_detector.py
during student registration.

A small sample folder (CS101_JohnDoe/) with 3 placeholder images is
included so you can see the expected structure and immediately try
out src/face_trainer.py. Delete it before training on real students.
